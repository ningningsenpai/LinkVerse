## 1. 交付范围

阶段 3 已增加商品、库存、订单和订单项四张业务表，并通过 `local` Profile 提供两条演示商品。Trade 服务已实现商品查询、幂等立即购买、订单所有者查询和只读过期候选扫描。

普通下单以 MySQL 为唯一事实源：订单、条件扣库存和价格快照在同一事务内完成，不依赖 Redis 或 RabbitMQ。客户端仅提交商品编号和固定数量 `1`；买家、卖家、金额、币种、订单状态及过期时间均由服务端确定。

- 相同幂等键重放返回原订单，同键异请求拒绝；
- 100 个同键并发请求只形成一个订单与快照，并且只扣一次库存；

- 订单项写入失败时订单和库存全部回滚；
- 商品改价、改名后既有订单快照保持不变；
- 过期候选按 `(expire_at, id)` 稳定分页且扫描不改状态；
- 非订单所有者无法读取订单。
